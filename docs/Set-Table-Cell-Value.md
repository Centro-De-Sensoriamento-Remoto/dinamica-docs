# Set Table Cell Value

## Description

Inserts a value into a table.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Table | [Table Type](Table-Type.html) | Table where the value will be inserted. |
| Column | [Index Or Name Type](Index-Or-Name-Type.html) | Name or index of the column where the new value will be inserted. |
| Keys | [Tuple Type](Tuple-Type.html) | Keys corresponding to the row where the value will be inserted. |
| Value | [Table Value Type](Table-Value-Type.html) | Value that will be inserted into the table. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Result | [Table Type](Table-Type.html) | The resulting table containing the new value. |
