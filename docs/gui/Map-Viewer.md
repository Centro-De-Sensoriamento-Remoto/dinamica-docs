# Map Viewer

The Map Viewer displays and interprets raster maps, including the results of simulations. With it you can adjust display colors, check the categories of a map, zoom into regions, apply transparency, calculate expressions over a set of related maps, and create movies from a series of maps.

## Opening the Map Viewer

- From the main menu of the interface, with the "Open Map Viewer" icon, or with **Ctrl+M**.
- From the Sketch toolbar, with the "Inspect Functor" icon (the eye).
- From the eye icon of the [Load Map](../functors/Load-Map.html) and [Save Map](../functors/Save-Map.html) functors.
- As a separate application, from the Windows Start menu.
- From the Output pages of a [wizard](Functor-And-Port-Editors.html#wizards) created to present resulting maps.
