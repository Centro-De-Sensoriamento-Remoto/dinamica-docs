# Keyboard Shortcuts

## Global Actions

| Action | Shortcut |
|---|---|
| Carrier Remapper | Ctrl+J |
| Copy | Ctrl+C |
| Create or Edit Wizard | Ctrl+W |
| Create Submodel | Ctrl+K |
| Cut | Ctrl+X |
| Debug Script | Ctrl+D |
| Delete | Backspace / Delete |
| Dump Functor List | Ctrl+Alt+D |
| Exit | Alt+F4 |
| Expand Submodel | Ctrl+E (*) |
| Find | Ctrl+F |
| Help | F1 |
| Import Selected Submodel | Ctrl+I |
| Map Viewer | Ctrl+M |
| Most Recent Selection | Alt+Up |
| New Script | Ctrl+N |
| Next Selection | Alt+Right |
| Notification | Ctrl+T |
| Open Script | Ctrl+O |
| Paste | Ctrl+V |
| Paste Disconnected | Ctrl+Shift+V |
| Previous Selection | Alt+Left |
| Print Script | Ctrl+P |
| Run Script | Ctrl+R |
| Save Script | Ctrl+S |
| Select All | Ctrl+A |
| Select Children | Ctrl+Alt+A |
| Select None | Ctrl+Shift+A |
| Show Script Dependency Graph | Ctrl+U |
| Submodel Manager | Ctrl+G |
| Submodel Store | Ctrl+E (*) |

(*) Expand Submodel and Submodel Store share the **Ctrl+E** shortcut. The behavior may depend on context.

## Script Graph

| Action | Shortcut |
|---|---|
| Execute Layout | Ctrl+L |
| Execute Layout + Center on Selection | Ctrl+Shift+L |
| Cancel Editing | Escape |

## Window Size Presets

| Action | Shortcut |
|---|---|
| Set Window 1280×720 | Ctrl+Alt+7 |
| Set Window 1920×1080 | Ctrl+Alt+8 |

## Weights Editor

| Action | Shortcut |
|---|---|
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Confirm | Enter |
| Cancel | Escape |

## Debug Monitor / Script Runner

| Action | Shortcut |
|---|---|
| Stop / Clear Output | Ctrl+Backspace / Ctrl+Delete |
