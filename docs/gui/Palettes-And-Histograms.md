# Palettes and Histograms

Cell values are first transformed by the histogram, which resamples them to the range [0, 255], and then colored by the palette. The two are set per map from the map's row in the [Maps stack](Map-Viewer-Interface.html#map-functions).

## Color Palette

The palette defines the color of each cell in the visualization area. Cell values are first extracted from the map in their original range and resampled with the [histogram curve](Palettes-And-Histograms.html#histogram-editor). The resulting values fall in the range [0, 255], which is mapped to the palette colors.

![Color palette](../image/map_viewer_palette.png)

### Changing Colors Individually

Click a color square to change that color. Hovering over a square shows its color index.

![Color square](../image/map_viewer_palette_color.png)

![Color index on hover](../image/map_viewer_palette_color_hover.png)

> **Important:** Values changed by a [histogram transformation](Palettes-And-Histograms.html#histogram-editor) may not correspond to the expected palette colors, especially when editing the colors of specific cells or categories. Set the histogram transformation to None before editing the colors for specific cell values.

### Generated Palette

A palette can be generated by linear interpolation between two colors (a gradient). Click the gradient button and set the range.

![Gradient](../image/map_viewer_palette_gradient.png)

Then click the interpolate button to generate the new palette.

### Saving Your Work

Palettes are not saved until you choose to save them. Click Cancel to discard mistakes. Clicking Ok changes the palette locally, but the change is lost when the application restarts unless the palette is saved.

Saved palettes are stored in the user palette folder `Dinamica EGO/Dmps`, so they are available every time the Map Viewer is opened. Changes to predefined palettes affect only the user's own instance of the application. To restore the predefined palettes, remove the user palette folder and restart the application.

> **Tip:** The user palette folder is usually `C:\Users\<User Name>\Documents\Dinamica EGO\Dmps`.

## Histogram Editor

The histogram window assigns a transformation from the original cell values (in any range) to the [palette](Palettes-And-Histograms.html#color-palette) range [0, 255]. Values smaller than the "From" limit become 0, and values greater than the "To" limit become 255. All other values are mapped through the histogram curve to the "Y" coordinate on the color palette on the left.

![Histogram editor](../image/map_viewer_histogram.png)

### Transformations

- **None**: no mapping. Cell values are used as they are.
- **Linear**: maps values linearly between the "From" and "To" limits.
- **Equalize**: builds a curve based on [histogram equalization](https://en.wikipedia.org/wiki/Histogram_equalization).
