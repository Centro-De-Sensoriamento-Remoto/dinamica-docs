# Index Or Name

## Description

Declares a value that can hold either an index or a name, so that it can be reused as the input to more than one functor instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Index Or Name Type](Index-Or-Name-Type.html) | Value or constant representing an index or a name. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Index Or Name Type](Index-Or-Name-Type.html) | Value or constant representing an index or a name provided as the functor input. |

## Group

[Control](Functor-List.html#control)

## Notes

None.
