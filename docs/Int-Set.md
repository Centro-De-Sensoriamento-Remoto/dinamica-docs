# Int Set

## Description

Declares a set of integer values that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Int Set Type](Int-Set-Type.html) | Integer set or constant. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Int Set Type](Int-Set-Type.html) | Integer set provided as the functor input. |

## Group

[Map Algebra Supplementary](Functor-List.html#map-algebra-supplementary)

## Notes

This functor was previously known as "IntList".
