# Cell Type

## Description

Declares a map cell type value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Cell Type](Cell-Type.html) | Value or constant representing a map cell type. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Cell Type](Cell-Type.html) | Value or constant representing a map cell type, provided as the functor input. |
