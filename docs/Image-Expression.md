# Image Expression

## Description

Declares a map algebra expression value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Image Expression Type](Image-Expression-Type.html) | Value or constant representing a map algebra expression. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Image Expression Type](Image-Expression-Type.html) | Value or constant representing a map algebra expression, provided as the functor input. |

## Group

[Map Algebra Supplementary](Functor-List.html#map-algebra-supplementary)

## Notes

None.

## Internal Name

ImageExpression
