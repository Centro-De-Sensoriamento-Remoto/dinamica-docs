# Folder

## Description

Declares a folder, directory, or zip file that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Folder Type](Folder-Type.html) | Folder, directory, or zip file, or constant representing one. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Folder Type](Folder-Type.html) | Folder, directory, or zip file provided as the functor input. |

## Notes
