# Real Value

## Description

Declares a double precision real value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Real Value Type](Real-Value-Type.html) | Value or constant representing a double precision real. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Real Value Type](Real-Value-Type.html) | Value or constant representing a double precision real, provided as the functor input. |
