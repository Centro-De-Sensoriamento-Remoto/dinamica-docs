# Weights

## Description

Declares a Weights of Evidence coefficients value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Weights Type](Weights-Type.html) | Value or constant representing Weights of Evidence coefficients. |

## Optional Inputs

## Outputs

| Object | [Weights Type](Weights-Type.html) | Value or constant representing Weights of Evidence coefficients, provided as the functor input. |
