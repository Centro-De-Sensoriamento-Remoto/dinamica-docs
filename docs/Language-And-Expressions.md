# Language and Expressions

The notations for writing a model as text, and the expression languages used inside calculator functors.

- [EGO Script Language](EGO-Script.html) — the primary text notation for writing a model: functor calls, constants, containers, the calculator shorthand family, properties, and submodels. Start here for the language itself.
- [EGOML Script](EGOML-Script.html) — the equivalent XML notation, generated by the GUI or written by hand, and its DTD.
- [Submodels](Submodels.html) — packaging part of a model as a reusable functor with its own declared inputs and outputs, so it can be called from other models the same way a built-in functor is: local, user, store, and system submodels, expansion before execution, publishing, and the Store; the interface workflow is in [Submodels in the GUI](gui/Submodels-In-The-GUI.html).
- [Calculate Functors — Complete Operator Documentation](Calculate-Functors.html) — the full expression language available inside a calculator functor: operators, functions, and the shorthand family (`#`, `##`, `$`, `%`, `%%`).
- [Calculate R Expression](functors/Calculate-R-Expression.html) — embedding R code in a model, including how tables, maps, and values convert between Dinamica and R.
- [Calculate Python Expression](functors/Calculate-Python-Expression.html) — embedding Python code in a model, including how tables, maps, and values convert between Dinamica and Python.
