# Change Matrix

## Description

Declares a change matrix value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Change Matrix Type](Change-Matrix-Type.html) | Value or constant representing a matrix of quantities of changes. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Change Matrix Type](Change-Matrix-Type.html) | Value or constant representing a matrix of quantities of changes, provided as the functor input. |
