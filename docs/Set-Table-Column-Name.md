# Set Table Column Name

## Description

Replaces the name of a column in a table or lookup table.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Table | [Base Table Type](Base-Table-Type.html) | Table or lookup table containing the column whose name will be changed. |
| Column | [Index Or Name Type](Index-Or-Name-Type.html) | Column whose name will be changed. |
| Name | [Name Type](Name-Type.html) | New name for the specified column. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Result | [Base Table Type](Base-Table-Type.html) | Table or lookup table with the column's name changed. |

## Group

[Table](Functor-List.html#table)

## Notes

None.

SetTableColumnName
