# Getting Started

Where to begin with Dinamica EGO.

- [Guidebook](guidebook/index.html) — the step-by-step course *Modeling Environmental Dynamics with Dinamica EGO*: data structures and the interface, working with maps and tables, submodels, control structures, spatial analyses, land-use change simulation, calibration, and case studies.
- [Dinamica Console](Dinamica-Console.html) — running a model script from the command line instead of the GUI: execution flags, worker and memory control, logging, accelerators, metadata, and converting a script to another format without running it.
