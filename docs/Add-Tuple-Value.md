# Add Tuple Value

## Description

Appends a value to the end of a given tuple.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Tuple | [Tuple Type](Tuple-Type.html) | Input tuple to which the value will be appended. |
| Value | [Table Value Type](Table-Value-Type.html) | Value to be appended to the tuple. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Result | [Tuple Type](Tuple-Type.html) | The resulting tuple after the value is appended. |

## Notes
