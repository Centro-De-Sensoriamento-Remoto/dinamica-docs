# Projection

## Description

Declares a map projection value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Projection Type](../types/Projection-Type.html) | Value or constant representing an image projection. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Projection Type](../types/Projection-Type.html) | Value or constant representing an image projection, provided as the functor input. |

## Group

[Map Algebra Supplementary](../Functor-List.html#map-algebra-supplementary)

## Notes

None.
