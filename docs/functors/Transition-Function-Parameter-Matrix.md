# Transition Function Parameter Matrix

## Description

Declares a transition function parameter matrix value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Transition Function Parameter Matrix Type](../types/Transition-Function-Parameter-Matrix-Type.html) | Value or constant representing a matrix of transition function parameters. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Transition Function Parameter Matrix Type](../types/Transition-Function-Parameter-Matrix-Type.html) | Value or constant representing a matrix of transition function parameters, provided as the functor input. |
