# Weights Of Evidence Skeleton

## Description

Declares a Weights of Evidence skeleton value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Weights Of Evidence Skeleton Type](../types/Weights-Of-Evidence-Skeleton-Type.html) | Value or constant representing a Weights of Evidence skeleton. |

## Optional Inputs

None.

| Object | [Weights Of Evidence Skeleton Type](../types/Weights-Of-Evidence-Skeleton-Type.html) | Value or constant representing a Weights of Evidence skeleton, provided as the functor input. |
