# Transition Matrix

## Description

Declares a transition matrix value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Transition Matrix Type](../types/Transition-Matrix-Type.html) | Value or constant representing a transition matrix. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Transition Matrix Type](../types/Transition-Matrix-Type.html) | Value or constant representing a transition matrix, provided as the functor input. |

## Group

## Notes

None.
