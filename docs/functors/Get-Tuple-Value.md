# Get Tuple Value

## Description

Gets a value from a tuple.

| Name | Type | Description |
| --- | --- | --- |
| Index | [Positive Integer Value Type](../types/Positive-Integer-Value-Type.html) | Index of the desired value in the tuple. |
| Tuple | [Tuple Type](../types/Tuple-Type.html) | Tuple to extract the value from. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Result | [Table Value Type](../types/Table-Value-Type.html) | Value extracted from the tuple. |
