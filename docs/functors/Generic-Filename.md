# Generic Filename

## Description

Declares a generic filename that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Generic Filename Type](../types/Generic-Filename-Type.html) | Generic filename or constant. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Generic Filename Type](../types/Generic-Filename-Type.html) | Generic filename provided as the functor input. |

[Map Algebra Supplementary](../Functor-List.html#map-algebra-supplementary)

## Notes

None.
