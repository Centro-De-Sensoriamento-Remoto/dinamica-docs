# Percent

## Description

Declares a percentage that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Percent Type](../types/Percent-Type.html) | Percentage or constant. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Percent Type](../types/Percent-Type.html) | Percentage provided as the functor input. |
