# Transition Set

## Description

Declares a transition set value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Transition Set Type](../types/Transition-Set-Type.html) | Value or constant representing a list of transitions. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Transition Set Type](../types/Transition-Set-Type.html) | Value or constant representing a list of transitions, provided as the functor input. |

## Group

[Simulation Supplementary](../Functor-List.html#simulation-supplementary)

## Notes

None.
