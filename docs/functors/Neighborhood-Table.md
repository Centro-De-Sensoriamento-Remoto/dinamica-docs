# Neighborhood Table

## Description

Declares a neighborhood table value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Neighborhood Table Type](../types/Neighborhood-Table-Type.html) | Value or constant representing a neighborhood table. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Neighborhood Table Type](../types/Neighborhood-Table-Type.html) | Value or constant representing a neighborhood table, provided as the functor input. |

## Notes
