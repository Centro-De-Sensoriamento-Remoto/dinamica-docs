# Log Tag

## Description

Declares a log level that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Log Tag Type](../types/Log-Tag-Type.html) | Log level or constant. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Log Tag Type](../types/Log-Tag-Type.html) | Log level provided as the functor input. |

## Group

[Control Supplementary](../Functor-List.html#control-supplementary)

## Notes

None.

## Internal Name

LogTag
