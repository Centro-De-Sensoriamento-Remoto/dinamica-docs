# Kml

## Description

Declares a KML value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Kml Type](../types/Kml-Type.html) | Value or constant representing a KML. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Kml Type](../types/Kml-Type.html) | Value or constant representing a KML, provided as the functor input. |
