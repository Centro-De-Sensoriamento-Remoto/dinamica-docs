# Boolean Value

## Description

Declares a boolean value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Boolean Value Type](../types/Boolean-Value-Type.html) | Boolean value or constant. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Boolean Value Type](../types/Boolean-Value-Type.html) | Boolean value or constant provided as the functor input. |

## Group

[Map Algebra Supplementary](../Functor-List.html#map-algebra-supplementary)

## Notes

This functor was previously known as "Bool".

## Internal Name

BooleanValue
