# Categories

## Description

Declares a categorization value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Categorization Type](../types/Categorization-Type.html) | Value or constant representing an image categorization. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Categorization Type](../types/Categorization-Type.html) | Value or constant representing an image categorization, provided as the functor input. |

## Group

None.
