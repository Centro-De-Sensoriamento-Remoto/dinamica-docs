# Map

## Description

Declares a map value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Map Type](../types/Map-Type.html) | Value or constant representing a map. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Map Type](../types/Map-Type.html) | Value or constant representing a map, provided as the functor input. |
