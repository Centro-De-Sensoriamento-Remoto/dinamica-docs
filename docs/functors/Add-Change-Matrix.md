# Add Change Matrix

## Description

This functor sums two matrices of quantities of changes.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Addend1 | [Change Matrix Type](../types/Change-Matrix-Type.html) | Matrix of quantity of changes. |
| Addend2 | [Change Matrix Type](../types/Change-Matrix-Type.html) | Matrix of quantity of changes. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Sum | [Change Matrix Type](../types/Change-Matrix-Type.html) | Matrix with the total quantities of changes. |

## Group

[Simulation](../Functor-List.html#simulation)

## Notes

None.
