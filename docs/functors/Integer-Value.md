# Integer Value

## Description

Declares an integer value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Integer Value Type](../types/Integer-Value-Type.html) | Integer value or constant. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Integer Value Type](../types/Integer-Value-Type.html) | Integer value or constant provided as the functor input. |

## Group

[Map Algebra Supplementary](../Functor-List.html#map-algebra-supplementary)

## Notes

This functor was previously known as "Int".

## Internal Name

IntegerValue
