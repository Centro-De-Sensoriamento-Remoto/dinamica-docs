# Add Tuple Value

## Description

Appends a value to the end of a given tuple.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Tuple | [Tuple Type](../types/Tuple-Type.html) | Input tuple to which the value will be appended. |
| Value | [Table Value Type](../types/Table-Value-Type.html) | Value to be appended to the tuple. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Result | [Tuple Type](../types/Tuple-Type.html) | The resulting tuple after the value is appended. |

## Group

[Table](../Functor-List.html#table)

## Notes

None.

See [AddTupleValue](../Manipulating-Tables-And-Lookup-Tables.html#addtuplevalue) in [Manipulating Tables and Lookup Tables](../Manipulating-Tables-And-Lookup-Tables.html) for how this functor is used together with other table functors.

## Internal Name

AddTupleValue
