# Null Value

## Description

Declares a null value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Null Value Type](../types/Null-Value-Type.html) | Null value or constant. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Null Value Type](../types/Null-Value-Type.html) | Null value provided as the functor input. |
