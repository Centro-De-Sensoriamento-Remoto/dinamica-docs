# Weights Filename

## Description

Declares a Weights of Evidence filename value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Weights Filename Type](../types/Weights-Filename-Type.html) | Value or constant representing a Weights of Evidence filename. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Weights Filename Type](../types/Weights-Filename-Type.html) | Value or constant representing a Weights of Evidence filename, provided as the functor input. |

## Group

[Simulation Supplementary](../Functor-List.html#simulation-supplementary)

## Notes

None.
