# Get Table Row

## Description

Retrieves a row from a table.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Keys | [Tuple Type](../types/Tuple-Type.html) | Keys corresponding to the desired row. |
| Table | [Table Type](../types/Table-Type.html) | Table to extract the row from. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Result | [Tuple Type](../types/Tuple-Type.html) | Row extracted from the table. |

## Group

[Table](../Functor-List.html#table)

## Notes

None.

See [GetTableRow](../Manipulating-Tables-And-Lookup-Tables.html#gettablerow) in [Manipulating Tables and Lookup Tables](../Manipulating-Tables-And-Lookup-Tables.html) for how this functor is used together with other table functors.

## Internal Name

GetTableRow
