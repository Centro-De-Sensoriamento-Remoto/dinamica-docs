# Kmz Filename

## Description

Declares a filename referring to a KMZ file that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Kmz Filename Type](../types/Kmz-Filename-Type.html) | Value or constant representing a KMZ filename. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Kmz Filename Type](../types/Kmz-Filename-Type.html) | Value or constant representing a KMZ filename, provided as the functor input. |

## Group

[Map Algebra Supplementary](../Functor-List.html#map-algebra-supplementary)

## Notes

Can be used to pass a constant filename to more than one functor, or to connect two or more functors.

## Internal Name

KmzFilename
