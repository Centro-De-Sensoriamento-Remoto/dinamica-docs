# Categorical Map

## Description

Declares a categorical map value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Categorical Map Type](Categorical-Map-Type.html) | Value or constant representing a map whose cells are categories. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Categorical Map Type](Categorical-Map-Type.html) | Value or constant representing a map whose cells are categories, provided as the functor input. |
