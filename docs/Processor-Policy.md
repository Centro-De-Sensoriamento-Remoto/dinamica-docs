# Processor Policy

## Description

This container forces the use of a maximum number of processors

## Inputs

None.

## Optional Inputs

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| Maximum Number Of Processors | [Non Negative Integer Value Type](Non-Negative-Integer-Value-Type.html) | Maximum number of processors. Set 0 for unlimited. | 0 |
| Force Specified Number Of Processors | [Boolean Value Type](Boolean-Value-Type.html) | Use strictly a specified number of processors. | False |

## Outputs

None.

## Group

[Control](Functor-List.html#control)

## Notes

None.

## Internal Name
