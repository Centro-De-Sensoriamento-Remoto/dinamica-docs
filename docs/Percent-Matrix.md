# Percent Matrix

## Description

Declares a percent matrix value that can be reused as the input to more than one functor, instead of repeating the same constant throughout the model.

## Inputs

| Name | Type | Description |
| --- | --- | --- |
| Constant | [Percent Matrix Type](Percent-Matrix-Type.html) | Value or constant representing a matrix of percents. |

## Optional Inputs

None.

## Outputs

| Name | Type | Description |
| --- | --- | --- |
| Object | [Percent Matrix Type](Percent-Matrix-Type.html) | Value or constant representing a matrix of percents, provided as the functor input. |
